# Must-Know Algorithms

---

## 1. Prefix Sum

### Idea

Store cumulative sums.

### Formula

```python
prefix[i] = prefix[i-1] + arr[i]
```

### Used In

* Subarray Sum Equals K
* Range sum queries

---

## 2. Kadane’s Algorithm

### Finds

Maximum subarray sum in O(n)

### Core Logic

```python
current = max(num, current + num)
best = max(best, current)
```

### Used In

* Maximum Subarray

---

## 3. Boyer-Moore Voting Algorithm

### Finds

Majority element in O(n)

### Used In

* Majority Element
